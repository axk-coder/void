PROJECT MAP: void (Vite + Modular Vanilla JS)

ROOT:
- index.html: Root HTML template mounting application shell, fonts, styles, and scripts.
- package.json: NPM configuration, Vite build/dev/start/deploy scripts.
- vite.config.js: Vite configuration (no websockets, relative base).
- deploy.sh: Automated build and git push deployment script.
- public/games/: Built-in offline playable HTML5 game catalog.
  - 2048/index.html (Puzzle)
  - snake/index.html (Arcade)
  - tetris/index.html (Puzzle)
  - flappy/index.html (Arcade)
  - pong/index.html (Multiplayer)
  - breakout/index.html (Arcade)
  - space-invaders/index.html (Action)
  - minesweeper/index.html (Puzzle)
  - asteroids/index.html (Action)
  - tictactoe/index.html (Multiplayer)
- src/
  - main.js: App entry point, games library, state orchestration, theme loader, auth check, shared cookie sync.
  - services/
    - playfab.js: PlayFab client SDK (Title ID 133616), auth endpoints, token persistence, cookie management, profile sync.
    - state.js: Reactive central application state store.
    - soundEffects.js: Web Audio API sound synthesis.
  - components/
    - AuthModal.js: axk-auth modal supporting Login, Register, Forgot Password with VOID branding.
    - SettingsModal.js: Settings dialog (Profile, Account, Preferences, Policies).
    - LegalModal.js: Privacy Policy, Terms of Service, Copyright tabs.
    - CreditsModal.js: Project and open source acknowledgements.
    - GamePlayer.js: Sandboxed game player frame with fullscreen and reload controls.
  - styles/
    - variables.css: Theme variables (onyx, amoled, blurple, cyberpunk, emerald, crimson, sapphire, amethyst, amber, slate).
    - main.css: Core application styles, layout, components, user profile panel, modals, animations.
- task.md: Task checklist.
- map.txt: Project architecture map.
